 Calculator – CodeAlpha Internship Project

 About the Project

This Calculator is a frontend development project created as part of my CodeAlpha Frontend Development Internship. The main purpose of this project was to practice HTML, CSS, and JavaScript and learn how to build a simple and interactive web application.

The calculator provides a simple interface that allows users to perform basic mathematical calculations easily. It is designed to be user-friendly, with clearly arranged buttons and a display area for showing numbers and calculation results.

 Features

Basic Arithmetic Operations: The calculator supports addition, subtraction, multiplication, and division.
Interactive Buttons: Users can enter numbers and perform calculations by clicking the buttons.
Display Screen: Shows the entered numbers and calculated results.
Clear Function: Allows users to clear the current input and start a new calculation.
Simple Design: The interface is clean and easy to understand.
Responsive Layout: The layout is designed to work on different screen sizes.

 Technologies Used

HTML: Used to create the structure of the calculator.
CSS: Used to style the calculator, buttons, display screen, and overall layout.
JavaScript: Used to handle user interactions, mathematical operations, and calculation logic.

 How It Works

Users can click the number buttons to enter values and select an arithmetic operator to perform a calculation. After entering the required numbers, they can calculate the result using the equals button. The clear button helps them reset the input and perform another calculation.

 Learning Outcomes

During this project, I practiced writing HTML, styling elements with CSS, and using JavaScript to add functionality to a webpage. I also gained experience in connecting frontend components with JavaScript logic and improving the user interface.

This project helped me strengthen my understanding of basic frontend development concepts and gave me practical experience in creating a functional web application.
